# 전체 단원 기록 저장

2026-09-13, 기반 커밋 e8e7292 이후 codex/all-unit-records에서 구현.

## 학생의 사용 흐름

각 단원에서 퀴즈나 실습을 진행한 뒤 **내 기록에 저장**을 누릅니다. 퀴즈와 실습은 별도의 활동으로 남으며, 틀린 답과 작성 중인 내용도 저장합니다. 저장 버튼은 3개 단원 모두 공통으로 제공하고 기존 추상화 결과 카드·샌드위치 결과·순서도 작품 버튼에도 연결했습니다. 이미지·텍스트 복사는 보조 기능으로 유지합니다. 복사 자체는 서버 저장 완료를 뜻하지 않습니다.

비로그인 상태에서 저장을 누르면 먼저 그 시점의 내용을 보존한 뒤 로그인 창을 엽니다. 로그인 후 같은 활동에서 저장을 이어갑니다. 로그인 완료 문구를 계속 띄우지 않으며 저장 성공 알림은 4.5초 뒤 사라집니다. 저장 중·실패 상태는 성공으로 표시하지 않습니다.

## 저장 내용

| 단원 | 퀴즈 | 실습 |
|---|---|---|
| 문제 추상화 | 4문항 답안 | 맛보기에서 선택한 상태·조건·덜어낸 정보, 실전 워크북의 현재·목표 상태·조건·남긴/버린 정보 |
| 알고리즘 설계 | 4문항 답안 | 학생이 전송한 명령(해석하지 못한 명령 포함), 로봇이 해석한 동작, 작성 중인 명령, 저장 당시 로봇 상태 |
| 순서도 연구소 | 4문항 답안 | 순차·선택·반복 퍼즐의 선택한 칸, 예시에서 펼쳐 본 단계, 나만의 순서도의 자연어 카드·기호·연결 |

예시에서 펼쳐 본 단계는 직접 작성한 작품·성취 점수가 아닙니다. 순서도의 기호·연결 수와 퀴즈 정답률도 학습 참고용이며 공식 과정점수로 환산하지 않습니다. 단원 기록은 저장 당시의 작품이며, 전체 수정 이력이나 AI 대화 전체를 수집하지 않습니다. 작품을 편집기에 다시 불러오는 기능은 이번 범위에 포함하지 않습니다.

## 데이터와 호환성

기존 `learning_classes/{classId}/students/{두 자리 번호}/submissions/{uuid}` 계층과 접근 권한을 유지합니다. 기존 schemaVersion 1의 추상화 통합 기록을 그대로 읽으며 새 기록은 schemaVersion 2로 단원·활동 종류를 명시합니다. 퀴즈는 문항별 선택 번호를 보관하고, 실습의 가변 길이 작품은 practice.stage와 practice.contentJson에 보관합니다. contentJson은 크기를 제한한 JSON 원본이며 출력 시 HTML로 실행하지 않습니다. JSON 형식을 읽지 못하면 해당 기록의 오류를 표시합니다.

Firestore 규칙은 단원·활동·문항·길이·소유자·서버 시각을 검사합니다. practice.contentJson 내부의 모든 블록 의미나 채점 정당성을 인증하는 규칙은 아닙니다. 수행평가 기록·채점 규칙은 그대로 유지하고, 평가 진행 중 수업 저장은 차단합니다.

저장 실패 후에는 원래 ID와 내용을 그대로 재시도하여 중복 생성을 막습니다. 미완료 저장이 있는 동안 다른 단원 기록을 대신 저장하지 않고 나의 기록에서 이전 저장을 먼저 재시도하도록 안내합니다.
