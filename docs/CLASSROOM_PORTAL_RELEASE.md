# 역할별 클래스룸 사용 안내

2026-09-13 구현. 최신 기능 명세는 PRD 9.8을 따릅니다.

- 학생: 우측 상단 로그인 → 학생 → 학급·번호·6자리 비밀번호 → 내 클래스룸.
- 교사: 우측 상단 로그인 → 교사 → Google 또는 교사 비상 로그인 → 반 선택.
- 열린 평가는 학생 첫 영역에 표시하며 제출 후에는 제출 완료만 표시합니다.
- 교사는 반 안에서 학생·학습 기록과 실시간 수행평가를 전환합니다. 평가 버튼에 대상 반이 표시됩니다.
- 학생 비밀번호는 새로 갱신한 scratch/private-access/INDEX.md의 반별·학생별 자료를 배부합니다. 이전 비밀번호는 사용하지 않습니다. 교사 비상계정은 유지합니다.
- 일반 수업은 로그인 없이 둘러볼 수 있습니다. 수업 제출과 수행평가에는 학생 로그인이 필요합니다.
- 공유 PC에서는 우측 상단 계정 메뉴의 로그아웃 · 사용 종료를 누릅니다.

검증 범위와 남은 한계는 PRD 9.8 및 scratch/release-qa/portal-live.json에 기록했습니다. Google 로그인 팝업 자체는 아직 실제 검증하지 않았습니다.
