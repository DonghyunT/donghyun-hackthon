## 피드백과 방향

기존 지도는 화면 높이에 맞추느라 PC에서 작게 보였고, 둥근 벡터 그림은 사용자가 원한 ZEP 계열 픽셀아트의 느낌과 달랐다. 첨부한 캐릭터/공간 이미지를 스타일 참고로 사용하여 새 비트맵 시안을 생성했다. 참고 이미지의 캐릭터나 고유 자산을 그대로 복제하지 않았다. 교과서는 생성 입력에 사용하지 않았다.

- 대문: PC 화면 너비 약 90%, 최대 약 1680px를 목표로 넓게 사용한다. 16:9 기반의 넓은 지도로 구성하고 상단 제목·안내를 간결하게 한다. 한 화면 안에 모든 것을 넣기 위해 지도 자체를 과도하게 줄이는 기존 높이 제한은 대체한다. 낮은 화면에서는 짧은 세로 스크롤을 허용하고 조작 바를 쉽게 찾도록 한다. 최종 폭은 대표 화면에서 확인한다.
- 맵: 미세한 픽셀 질감, 지붕·벽돌·창문·나무·길의 음영과 디테일을 살린다. 현재 지도보다 색과 대비를 명료하게 하되 서비스의 차분한 UI와 연결한다.
- 건물: 중앙 위 알고리즘, 중간 좌우 컴퓨팅/데이터, 아래 좌우 AI/디지털 문화의 대칭 배치를 유지한다. 단원별 상징을 간판에 담고 실제 단원 이름은 HTML 글자로 얹는다.
- 캐릭터: 기존 로봇 정체성을 픽셀아트로 발전시킨다. 아래·왼쪽·오른쪽·위의 네 방향, 방향별 정지/걷기 두 자세를 구분한다. 위로 갈 때는 얼굴 대신 등과 배터리 팩이 보인다.
- 접근성: 기기의 움직임 줄이기 설정은 자동 존중한다. 클릭할 수 없는 ‘기기 설정: 움직임 줄이기’ 버튼을 대문에서 제거한다. 필수 이동과 방향 전환은 유지하고 장식적 등장·흔들림을 제한한다. 필요하면 조작 안내의 설명으로 전달하되 비활성 버튼을 장식으로 두지 않는다.

## 생성한 시안

- 맵과 5건물: `scratch/pixel-art-direction/campus-v2.png`
- 캐릭터 4방향·걷기 자세: `scratch/pixel-art-direction/robot-directions-v1.png`

첫 맵 시안 중앙의 로봇 조형물과 화단은 실제 조작 캐릭터와 혼동될 수 있어 제거했다. 중앙 광장은 비어 있는 이동 공간이다. 두 파일은 렌더링 검토용이며 scratch 안에 보관하여 Git과 배포에 포함하지 않는다.

## 실제 구현으로 연결할 순서

1. 이번 그림으로 픽셀 밀도, 건물 표현, 캐릭터 방향을 먼저 맞춘다.
2. 캐릭터 배경을 투명화하고 방향별 프레임의 크기·중심·발바닥 기준선을 정렬한다. 현재 생성된 시트는 시각 검토용이며 그대로 잘라 쓸 수 있는 정규 애니메이션 시트라고 간주하지 않는다.
3. 맵의 건물·문 좌표와 클릭/충돌 영역을 새 구도에 맞춰 조정한다. 장식물 위를 걷지 않도록 이동 영역을 설계하고 모든 문에 실제로 도달하는지 검사한다.
4. 넓어진 대문에 지도·웹 간판·캐릭터를 합성하고 기존 수업 패널·실습 경로를 연결한다. 이미지 자체에 메뉴나 학생 정보를 굽지 않는다. 비트맵 크기와 선명도를 확인하고 무리한 확대를 피한다.
5. 네 방향 이동·키 해제·화면 이탈·평가 잠금 및 모바일 탭 입장을 확인한다. 실제 캡처는 대표 화면에만 최소화한다.

이번 단계에서 홈페이지 크기·모션 버튼·운영 코드를 수정하거나 새 그림을 배포하지 않았다. 운영 서비스는 기존 검증된 0d00367 상태다.


## 후속 구현 완료

사용자가 시안 기반 빌드·운영 반영을 승인했다. 픽셀 맵, 하단 정문 출발, 4방향 로봇, 독립 수업 화면, 모션 버튼 제거를 구현했다. 생성된 로봇 스트립에 실제 알파가 없어 원본은 보존하고 표시 시 SVG 실루엣 마스크로 주변 배경을 가렸다. 실제 정문 캐릭터 렌더링을 확인했다. 걷기 프레임 대신 방향 변경과 짧은 움직임 효과를 적용했다. 추가된 학생/교사 발표 체험은 실제 인증과 별개의 샘플 전용이다. 최신 상태는 PRD9.12를 따른다.
