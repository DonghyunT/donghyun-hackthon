# 정보 놀이터 지도 홈 — 배포 준비 및 검증 기록

2026-09-13 · 기반 운영 커밋 cf504e6 · 작업 브랜치 codex/playground-campus

## 변경된 경험

- 홈을 중앙 알고리즘 연구소와 좌우 두 쌍의 건물로 구성한 대칭 2D 지도로 바꿨다. 컴퓨팅·데이터·알고리즘과 프로그래밍·인공지능·디지털 문화의 5개 영역을 담는다.
- 캐릭터는 지도에 포커스를 둔 상태에서 방향키로 움직이며, 문 근처에서 Enter 또는 입장 버튼으로 영역을 연다. 건물·간판·아래 큰 바로가기 버튼을 클릭해도 같은 내용을 연다.
- 총 25개 세부 주제에 직접 작성한 소개와 질문을 제공한다. 알고리즘 영역은 기존 문제 추상화·알고리즘 설계·순서도 연구소의 개념/퀴즈/실습으로 이어진다. 나머지 실습은 준비 중이라고 명시한다.
- 첫 입장 연출은 짧게 한 번만 실행하고 창 단위로 위치를 복구한다. 움직임 줄이기와 기기 접근성 설정을 지원한다. 이동·탐색은 서버로 기록하지 않는다.
- 기존 로그인·기록·평가 API와 Firebase 데이터/권한/채점 정책은 수정하지 않았다. 기존 화면 전환 함수에 지도 종료 호출을 추가해 직접 클래스룸 이동 등에서도 키 상태와 루프를 정리한다.

## 참고와 자료 취급

ZEP 공식 소개 https://web-app.zep.us/en 와 공식 공간 안내 https://docs.zep.us/ 를 참고했다(2026-09-13). 위에서 보는 지도, 작은 아바타와 위치 기반 목적지 선택이라는 원리를 가져왔으며 SVG 지도·건물·캐릭터는 자체 제작했다. 영상, 게임 엔진, 추가 외부 라이브러리, 실시간 다중 사용자 기능은 추가하지 않았다.

schoolbooks의 교과서 목차만 로컬 참고했다. 원본·이미지·교과서 본문을 앱에 포함하거나 외부로 업로드하지 않았다. .gitignore의 기존 *.pdf 규칙 외에 schoolbooks/를 명시하고 .vercelignore에도 schoolbooks 및 *.pdf 제외를 추가했다. git ls-files schoolbooks는 0개, 폴더 내 일반 파일과 PDF 모두 git check-ignore로 제외됨을 확인했다. 추출 자료를 제품 경로에 생성하지 않았다.

## 검사 근거

대상: 위 기반 이후 이번 작업 파일. 환경: Windows, 로컬 정적 미리보기 + Codex 내장 브라우저. 로컬 미리보기는 실제 Firebase 쓰기와 AI 요청을 실행하지 않는다.

- node tools/check.cjs: 스크립트 63개 문법 및 HTML의 로컬 자산 참조 통과.
- node --test tests/*.test.cjs: 42/42 통과. 기존 33개와 독립 검토자가 작성한 지도 9개. 지도 검사는 실제 컨트롤러를 VM의 모의 DOM/시간에 연결하여 5문 이동, 충돌, 멈춤, 포커스/뷰 이탈, 평가/교사 잠금, 위치 복구/손상값, reduced-motion, 첫 등장 종료를 확인한다.
- 실제 브라우저: 방향키로 알고리즘·컴퓨팅·데이터·AI·문화의 문까지 이동하고 Enter로 각각 올바른 영역을 열었다. 키를 놓은 뒤 걷기 상태가 남지 않았다.
- 실제 브라우저: 5개 건물 클릭, 간판 글자 직접 클릭, 주제 설명과 준비 안내, 3개 기존 활동의 올바른 개요 진입과 홈 복귀를 확인했다. 홈 이탈 시 지도 숨김과 걷기 종료를 확인했다. 이 흐름의 브라우저 오류 로그 0개.
- 1280×720: 페이지 최상단 기준 지도 x302/y215, 약 660×409px, 조작 바 하단 y686. 다섯 건물이 한 화면에 표시되고 가로 넘침이 없다.
- 390×844: 대칭 지도와 큰 2열 바로가기 확인. 알고리즘 패널 약343×726px, 닫기 버튼 접근 가능. 활동 버튼 3개 약289×88px이며 내부 가로 잘림과 페이지 가로 넘침 없음. 주제 목록은 패널 내부에서 스크롤된다.
- 최소 대표 캡처로 시각 점검하고 나머지는 DOM/코드/조작으로 확인했다. 지도는 저해상도에서 간판이 작아지지만 큰 바로가기와 접근 가능한 이름을 함께 제공한다.

독립 검토 과정에서 첫 입장 연출 재생 방지, 간판 클릭 범위, OS 움직임 줄이기 상태 문구를 보완했다. 최종 내부 평가는 [PLAYGROUND_REVIEW.md](PLAYGROUND_REVIEW.md)를 따른다. 점수는 확인한 범위의 내부 평가이며 모든 환경의 무결점을 뜻하지 않는다.

## 배포 범위와 남은 한계

사용자가 이번 지도 홈 변경의 구현·커밋·운영 병합·배포를 명시적으로 승인했다. 대상은 DonghyunT/donghyun-hackthon 저장소의 feature/hackathon과 donghyun-hackthon.vercel.app이다. 이전 서비스와 Firebase 운영 데이터를 변경하지 않는다.

Vercel 프로젝트 prj_2O0qOyxdhxRL5uEOTPiM6dnrH6sx의 Git 연결과 운영 브랜치를 배포 전에 읽어 확인했다. 최종 병합 커밋·Production READY·도메인의 새 자산 확인 결과는 배포 후 최종 응답과 비공개 scratch 배포 영수증에 기록한다.

모바일에서 방향키 UI는 제공하지 않고 탭 입장을 사용한다. 실제 교실 PC 대규모 동시 접속, 모든 브라우저/보조공학 조합, 이번 범위에서 바뀌지 않은 전체 로그인·평가의 실서버 재시험은 하지 않았다. 시스템 접근성 설정이 움직임 줄이기이면 장식 모션을 우선 제한한다. 새로운 영역의 퀴즈·실습, 학생 간 아바타 공유, 서비스 전체 전환 개선은 후속 작업이다.

문제 발생 시 이번 병합을 되돌리거나 이전 Vercel 배포를 다시 운영 대상으로 지정한다. 데이터 구조 변경이 없어 별도 DB 되돌리기는 필요하지 않다.
