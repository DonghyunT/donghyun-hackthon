# UX 후속 작업

## 낮은 우선순위: 조작과 화면 전환의 연속성

2026-09-13 사용자 요청: 애플 UX에서 느끼는 것처럼 대부분의 클릭·페이지 이동이 부드럽고 자연스럽게 이어지기를 원함. 이번 전체 단원 기록 구현에서는 후속 과제로 기록하며 전면 적용하지 않는다.

- 클릭 즉시 눌림·처리 중 상태를 보여주고, 늦은 응답 때문에 같은 버튼을 반복해서 누르지 않도록 한다.
- 단원·클래스룸·기록 이동 시 화면이 갑자기 튀거나 빈 화면이 깜빡이지 않도록 전환과 로딩 상태를 정리한다.
- 뒤로 돌아왔을 때 이전 스크롤·선택 맥락을 보존하고, 필요한 경우에만 화면을 이동한다.
- 모달·메뉴·기록 펼치기를 짧고 일관된 전환으로 연결한다. 애니메이션 때문에 입력이나 저장을 지연시키지 않는다.
- `prefers-reduced-motion`을 존중하고 교실 PC에서도 프레임 끊김 없이 작동하도록 검증한다.
- 대표 경로(수업 → 활동 → 기록 저장 → 내 클래스룸)를 먼저 검토하고 적용 범위·전환 시간을 확정한 뒤 확대한다.

이는 특정 회사의 화면 복제나 공식 UX 철학 분석을 뜻하지 않는다. 학생이 조작 결과를 예측하고 작업 흐름을 이어갈 수 있도록 개선한다는 제품 방향이다.
